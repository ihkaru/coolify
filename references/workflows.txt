🚀 Step-by-Step: Code on Laptop → Deploy to Office PC
Step 1: Start a New Project on Your Laptop
bash# On your laptop (anywhere in the world)
mkdir my-awesome-project
cd my-awesome-project

# Initialize git
git init

# Create a simple project (example: Node.js)
echo "console.log('Hello from my laptop!');" > index.js

# Create package.json
cat > package.json << EOF
{
  "name": "my-awesome-project",
  "version": "1.0.0",
  "scripts": {
    "start": "node index.js"
  }
}
EOF

# Create Dockerfile (so Coolify knows how to deploy)
cat > Dockerfile << EOF
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
CMD ["npm", "start"]
EOF
Step 2: Push to GitHub from Your Laptop
bash# Create repo on GitHub (via web or GitHub CLI)
# Then:

git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/yourusername/my-awesome-project.git
git push -u origin main
Step 3: Deploy via Coolify (From Anywhere!)
Option A: Via Coolify Dashboard (laptop browser)

Open https://coolify.yourdomain.com (from your laptop!)
Login with your credentials
Projects → + New Application
Select your GitHub repo: yourusername/my-awesome-project
Set domain: awesome.yourdomain.com
Click Deploy

Option B: Enable Auto-Deploy (Set Once, Forget Forever)
Once you enable webhook (Step 5 from previous guide):
bash# Just code and push - that's it!
git add .
git commit -m "Updated feature"
git push

# Coolify auto-deploys in ~30 seconds ✨

💡 Pro Tips for Remote Development
1. Use Branches for Testing

git push origin dev

2. Environment-Specific Configs

API_KEY=prod-key

# .env.development (locally on laptop)

3. Quick Rollback

Click Deployments tab
